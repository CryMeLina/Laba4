# Laba4

Лабораторная работа № 4, вариант 20 «Патенты». Бот на Python получает карточку европейской патентной публикации по номеру. Вторая часть работы — анализ заявок по 13 технологическим направлениям за 2023 и 2024 годы.

## Запуск бота в Windows PowerShell

Понадобятся Python 3.11 или новее, доступ к сети и токен своего бота. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте /newbot и следуйте подсказкам. В каталоге проекта выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN = [System.Net.NetworkCredential]::new('', (Read-Host 'Токен Telegram' -AsSecureString)).Password
.\.venv\Scripts\python bot.py
```

Откройте диалог с созданным ботом и нажмите «Старт». Пока процесс работает, он получает сообщения через long polling. Для остановки нажмите Ctrl+C. В новом окне терминала переменную с токеном нужно задать заново.

| Ввод | Ответ |
|---|---|
| /start или /help | Инструкция и клавиатура |
| EP 1004359 B1 | Название документа, дата публикации, код вида и ссылка на PDF |
| /patent EP1004359B1 | Та же карточка |
| Кнопка «Пример» | Запрос образца к EPO |
| /format или кнопка «Формат» | Переключение между кратким и подробным видами |

Поддерживаются исходные публикации EP с семизначным номером и кодом вида A или B с цифрой, для которых EPO предоставляет XML через European Publication Server. Поиск идёт по номеру публикации. Код NW в адресе сервиса добавляется автоматически. Бот предпочитает английское название, если оно есть в документе.

## Как устроен проект

- `bot.py` принимает сообщения через python-telegram-bot, вызывает поиск и отправляет ответ. В таблице SQLite хранятся Telegram ID и один признак подробного формата. Для нового пользователя подробный режим включён.
- `patents.py` проверяет номер, запрашивает XML по HTTPS, извлекает название и дату публикации. Отдельно обрабатываются неверный ввод, отсутствие документа, тайм-аут и повреждённый ответ.
- `analysis/epo.csv` содержит данные по секторам Electrical engineering и Instruments из одной версии Patent Index 2024. Строка соответствует направлению.
- `analysis/analysis.ipynb` содержит подготовку данных, график, статистическую проверку и вывод. Готовый график сохранён в `analysis/change.png`.
- `report.pdf` содержит отчёт и вопросы с ответами для защиты.

## Как повторить анализ

В Google Colab откройте analysis.ipynb, загрузите epo.csv в панель «Файлы» и выполните все ячейки. Для локального запуска установите `jupyterlab pandas numpy matplotlib` в виртуальное окружение, откройте блокнот из папки analysis и выберите ядро этого окружения. Для генератора перестановок зафиксировано начальное значение 42.
